# Python Grade Calculator 

A simple beginner-friendly Python project that calculates a student's percentage and assigns a grade based on the percentage obtained.

##  Features

- Takes obtained marks and total marks as input.
- Calculates the percentage.
- Assigns a grade based on percentage ranges.
- Validates inputs to prevent invalid marks.
- Displays the final percentage and grade.

## Grading Scale

| Percentage | Grade |
|---|---|
 90% and above | A+ 
 80% – 89.99% | A 
 70% – 79.99% | B 
 60% – 69.99% | C 
 50% – 59.99% | D 
 Below 50% | Fail 

## How to Run

1. Install Python 3 on your computer.
2. Clone this repository or download the project files.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
 Grade_Calculator.py
```

5. Enter your obtained marks and total marks when prompted.

##  Example Output

```text
Enter your obtained marks: 85
Enter your total marks: 100
Your percentage is: 85.0%
Your Grade is: A
```

## Input Validation

The program checks for:
- Total marks less than or equal to zero.
- Obtained marks greater than total marks.
- Negative obtained marks.
